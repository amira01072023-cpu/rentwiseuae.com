# UX Audit — 2026-03-23

## Scope
Current MVP review based on the implemented pages and flows:
- homepage
- unified decision tool
- move-in calculator
- monthly cost calculator
- salary safety calculator
- generic comparison page
- dedicated compare pages
- area guides

## Overall impression
The product is already useful and more coherent than a typical early prototype. The strongest part is that the site now has a clear decision-making shape rather than isolated calculators.

## What is working well
### 1. Strong core value proposition
The product clearly centers on a useful renter question: the true cost of renting in the UAE.

### 2. Good page-to-page journey
Area guides, comparison pages, and tools now connect in a way that supports real exploration.

### 3. Assumptions are visible
This is a trust advantage. Many rent tools hide assumptions or pretend precision.

### 4. Dedicated comparison pages are a smart move
They make the product feel more intentional and more SEO-ready.

### 5. Prefilled defaults improve usability
Opening tools with selected area or pair already loaded makes the product feel smarter.

## Main UX issues to address next

### Issue 1: Too many entry points on the homepage
The homepage is much better than before, but it still offers a lot of possible paths at once.

#### Recommendation
Visually emphasize just 2 main paths:
- Start with unified decision tool
- Compare two areas

Keep other tools as secondary links.

### Issue 2: Tool pages do not yet feel like one connected workflow
Each page is useful, but the product still feels partly like a collection of tools.

#### Recommendation
Add a small summary strip or progress cue near the top of the main tools, such as:
- 1. Estimate move-in cash
- 2. Estimate monthly burden
- 3. Check salary fit

### Issue 3: No visual highlight of assumptions risk or confidence
Users may still not understand which numbers are more stable and which are rougher.

#### Recommendation
Add lightweight labels like:
- more stable estimate
- moderate estimate confidence
- rough planning estimate

### Issue 4: No “best next action” prioritization on result-heavy pages
There are next-step cards, which is good, but the product could still do more to suggest the single best next action.

#### Recommendation
On each page, make one next step primary and the rest secondary.

### Issue 5: Area guides could feel more opinionated
The guides currently expose data and fit notes, but they could offer a stronger human recommendation.

#### Recommendation
Add a short “This area is best if…” section near the top.

### Issue 6: Comparison pages could use clearer recommendation language
The quick verdict is helpful, but it can be made more scannable.

#### Recommendation
Use a compact verdict pattern:
- Better for budget: X
- Better for access: Y
- Better for families: Z

### Issue 7: Homepage examples are static copy
They help framing, but eventually they should become calculated previews or more evidence-backed sample scenarios.

#### Recommendation
Later, replace static example cards with dynamic scenario cards using real helper outputs.

## Best immediate UX improvements
1. Promote the unified decision tool more strongly than other tools
2. Add a small workflow/progress strip to main tools
3. Add “best if…” summaries to area guides
4. Add structured verdict bullets to compare pages
5. Reduce homepage visual competition a bit

## Implementation status update
These immediate improvements have now been applied in the current MVP:
- homepage emphasis now favors the unified decision tool and area comparison more strongly
- a workflow strip was added to the main tool pages
- area guides now include a stronger “This area is best if…” summary
- dedicated compare pages now include structured verdict bullets for budget, access, and family fit

## What should wait
- animation polish
- map UI
- account features
- saved scenarios
- highly detailed filtering

## Conclusion
The MVP is already credible enough to continue with refinement. The next UX gains will come from better prioritization and clearer guidance, not from adding many more pages.
