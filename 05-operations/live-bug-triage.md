## Quick severity guide
### High
- crash
- blank page
- broken core flow
- wrong calculation that misleads users badly

### Medium
- confusing UX that blocks progress
- prefilled links not carrying context correctly
- ugly layout that harms usability

### Low
- copy issue
- spacing issue
- polish improvement
